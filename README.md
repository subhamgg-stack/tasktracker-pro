# TaskTracker Pro

A React-based task management application built to manage and organize daily tasks efficiently.

## Features
- Add, complete, and delete tasks
- Filter and search tasks by status and priority
- Built using React Hooks (`useState`, `useEffect`) and React Router DOM

## How to Run Locally
1. Clone the repository: `git clone https://github.com/subhamgg-stack/tasktracker-pro.git`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
